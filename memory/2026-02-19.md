# 2026-02-19 - AI API Flat Rate Options for OpenClaw

## User Request
Alexandre Sardinha quer API com preço fixo para usar com OpenClaw. Não quer pay-as-you-go por token.

## Key Findings

### OpenClaw Native OAuth Support (BEST OPTION)
OpenClaw supports OAuth subscriptions natively:
- **Claude Pro** ($20/mês) - Claude Opus 4.6, Sonnet 4.6
- **Claude Max** ($100-200/mês) - Everything unlimited
- **ChatGPT Plus** ($20/mês) - GPT-5.2 Instant, Thinking
- **ChatGPT Pro** ($200/mês) - GPT-5.2 Pro, unlimited

No hack needed - just OAuth login directly in OpenClaw!

### Synthetic.new - NEW Flat Rate API Service
- URL: https://synthetic.new
- Flat monthly subscription for open-source models
- Models: GLM-4.5, DeepSeek 3.1, Kimi K2, Qwen3 Coder 480B
- OpenAI-compatible API
- Works with Cline, Roo, KiloCode, Aider, etc.
- Found via Reddit: r/LocalLLaMA/comments/1n2u7yk

### Pay-as-you-go Problem (Reddit insight)
- With 128k context models, every message re-sends entire chat history
- A few hours of chat can burn $5-10
- This is why flat rate is essential for heavy usage
- Source: r/LocalLLaMA/comments/1meep6o

### Together AI & OpenRouter
- Both are pay-per-token only
- No flat rate plans available
- Good prices per token but can get expensive with heavy use
- Together AI: Kimi K2.5 ($0.50/$2.80), MiniMax M2.5 ($0.30/$1.20), GLM-5 ($1.00/$3.20)

### ChatGPT-to-API Workaround
- GitHub: https://github.com/xqdoo00o/ChatGPT-to-API
- Converts ChatGPT web subscription to API
- Works but requires running your own server
- Aurora: https://github.com/aurora-develop/aurora (free GPT-3.5)

## Recommendation
1. Claude Pro ($20/mês) via OAuth - best value, native support
2. ChatGPT Plus ($20/mês) via OAuth - GPT-5 access
3. Synthetic.new - for open-source models with flat rate
